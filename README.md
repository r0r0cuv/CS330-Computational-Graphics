# CS330-Computational-Graphics
3D workspace scene developed using C++ and OpenGL, featuring 3D modeling, textures, lighting, camera navigation, and interactive visualization.

# CS 330: Computational Graphics and Visualization  

## Project Overview  

For my final project I decided to make a 3D workspace scene using C++ and OpenGL in Visual Studio 2022. I took a picture of my workspace to use as my inspiration. I have my desk lamp, computer screen, printer, coffee cup, books and desk. 

While my scene does not resemble the picture exactly I was able to create all the objects using primitives, transforms, textures and lights. After finishing this project I understand computational graphics and how we can take basic primitives and make them into something more.

## Project Reflection  

### 1.  How Do I Approach Designing Software?  

After completing this project I have gained knowledge on how to design software. I picked a picture of my workspace and tried to identify all of the objects that I would need to recreate. Once I identified all the objects I began thinking about what shapes they could be. Cubes, cylinders, spheres, cones and planes are all examples of shapes I used. 

I was able to learn from this project that you should break down your ideas into smaller tasks. You should always think about where you want your objects to be, how big they should be, rotation and texture. These are all things I will remember when I am trying to design software in the future. 

### 2.  How Do I Approach Developing Programs?  

I learned how to iterate through developing my scene this semester. By developing small pieces of code and testing my program. I learned how to create objects and transform them, texture objects, light objects and move my camera. 

By iterating I was able to fix issues that came up throughout the development of my project. If something wasn't looking right or I got an error I would go back and debug my code. I had to debug my code to make sure my objects were in the correct location, my textures were showing and my lights were on my objects. 

As I worked through my milestones I became more familiar with using Visual Studio 2022 and debugging errors. I learned to debug and test my code as I went along with my project. 

### 3.  How Can Computer Science Help Me in Reaching My Goals? 

Computer science will help me reach my goals by learning new skills that I can use in my career. By taking this class I have learned how to use C++ and OpenGL to create a 3D scene. 

At my job I help with warehouse management and automation technology. There are many ways that I could use my knowledge of 3D scenes to benefit my job. Maybe creating a simulation of a warehouse or watching automated equipment complete tasks. 

In the future I hope to learn more about creating 3D scenes and how I can use my skills to my advantage.
